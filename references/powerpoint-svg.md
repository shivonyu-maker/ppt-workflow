# PowerPoint SVG 验收

使用目标模板实际的 `PageSetup.SlideWidth` 和 `SlideHeight`，记录单位为 pt 的插入矩形 `x`、`y`、`width` 和 `height`。用 SVG 的 `viewBox` 计算横纵坐标映射。更换模板时重新读取和校准，即使页面比例相同。

## 重建对象

- 标题、标签或正文视觉行使用完整的原生 SVG `<text>`。设定 `font-family`、`font-size`、`font-weight`、`fill`、`x`、`y` 与所需的 `text-anchor`。优先使用目标系统常见且可用的字体，避免依赖网络字体和外部 CSS。仅在一行确需局部变色或变字重时使用 `<tspan>`，并检查转形结果。
- 保持文字按整行或自然文本对象编辑，避免逐字元素、逐字定位、文字轮廓和文字图片。多行段落可以按视觉行重建，以转形后的可编辑性和排版稳定性为准。一个 SVG 文本元素是否形成一个 PowerPoint 文本框，以实测为准。
- 每幅原图使用一个完整内嵌的 `<image>`，确保移动文件后仍能显示。背景、边框和分隔线用少量原生形状。页面始终保留可编辑的文本和形状结构。

## 在目标 PowerPoint 内对照

将同一 SVG 插入目标模板并复制幻灯片。一张保留原始 SVG，另一张执行「转换为形状」。两张使用相同插入矩形，转换后保持对象的位置和尺寸。取消选中，在 PowerPoint 编辑画布检查，并导出同分辨率的两态图像进行对照。结合原生对象边界和实际字形，逐页检查字高、行宽、字距、基线、换行、段间距、右边界与图片位置。即使文字坐标相同，字形变大造成的溢出也需要修复。

同一文本的可见字高、整行宽度差异以 5% 以内为校准目标，横向起点偏差以页面宽度的 1% 以内为目标，基线偏差以页面高度的 1% 以内为目标。文字须保持在预定区域内，避免串栏、互相重叠或遮挡图片。修改字号、根尺寸或缩放等补偿参数后，将结果写进最终 SVG，按目标模板重新实测两态。

交付时逐页记录转形后的文本框、图片和其他形状数量，说明字体、测试环境和剩余差异。无法在目标 PowerPoint 上完成实测时，说明已做的检查，并标明双态验证待完成。跨设备使用其他字体时，字宽、字高和基线可能变化。
