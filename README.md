# PPT Workflow

一个用于制作 PPT 的 Codex Skill。它根据汇报主题组织材料和逐页内容，再按当次需求制作 HTML 放映稿、结构化 SVG 或 PowerPoint 文件。

## 适用场景

- **项目中期汇报**。根据立项书和阶段工作材料交代项目背景、当前进展、代表性成果、待验证的问题和下一步计划。按当次考核要求决定是否加入计划对照。
- **文献分享**。根据论文原文讲清研究问题、方法、关键图表、结论、局限和讨论点。
- **其他演示主题**。根据受众、汇报目的和已有材料确定取材范围与讲述顺序。

## 使用示例

在 Codex 中加载此 Skill 后，可以通过 `$ppt-workflow` 调用。附上模板及对应材料，并说明受众、汇报时长和所需交付格式。

```text
$ppt-workflow 根据附上的立项书、阶段工作材料和 PPT 模板，
为 12 分钟的项目中期汇报写逐页执行稿。重点讲已取得的成果、
证据支持到什么程度，以及下一步如何推进。先给我审阅文字稿。
```

```text
$ppt-workflow 根据附上的论文和 PPT 模板，准备一场 20 分钟的组会文献分享。
围绕研究问题安排内容，选出关键图表并写清读图顺序、主要结论和局限。
先给我逐页执行稿和讲稿备注。
```

## 制作流程

1. **逐页执行稿**。确定主线、页序、上屏文案、图表、来源与讲稿备注，交付整套文字稿确认。
2. **HTML 放映稿**。按确认稿制作可离线打开的预览，检查排版、图片与导航，整套确认后继续。
3. **结构化 SVG（按需）**。保留可编辑文本和完整原图，在 PowerPoint 中对照插入态与转形态。
4. **PPTX（按需）**。按确认稿组装，并核查放映效果和所需对象的可编辑性。

也可以从已有的确认稿继续，或直接指定需要交付的阶段。
